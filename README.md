# BrickGame: Snake & Tetris

## Описание

В этом проекте реализуются две классические аркадные игры — **Змейка** и **Тетрис** — с использованием C++ и графической библиотеки **Qt**. Проект построен по принципам модульности и разделения логики, что позволяет запускать игры как в консольном, так и в графическом интерфейсе.

- **Змейка** реализуется с нуля на C++ с объектно-ориентированным подходом и поддерживается как в графическом, так и в консольном интерфейсе.
- **Тетрис**, ранее написанный на C для консоли, адаптируется под графическую среду.

## Введение

Проект состоит из двух частей:

- **Библиотека**, реализующая логику игр.
- **Графический интерфейс** с использованием Qt.
- **Консольный интерфейс**: обе игры (Змейка и Тетрис) поддерживаются в консольной форме для совместимости и демонстрации абстрагирования логики от представления.

---

## Архитектура

Архитектура проекта следует принципу **MVC** (Model-View-Controller):

- **Model** — логика игры (движение, столкновения, очки и т.д.)
- **View** — графическое или консольное отображение
- **Controller** — обработка ввода и взаимодействие между Model и View

Особенности:

- Полная изоляция бизнес-логики от представлений
- Контроллеры не содержат бизнес-логику
- Возможность переиспользовать и расширять игру с минимальными изменениями

## Требования к проекту

- Язык: **C++20**
- Библиотека логики: `src/brick_game/`
- Графический интерфейс (Qt): `src/gui/desktop`
- Консольный интерфейс: `src/gui/cli`
- Использование **конечного автомата** для логики
- **Unit-тесты (GoogleTest)** — покрытие не менее 80%
- **Makefile** с целями: `all`, `install`, `uninstall`, `clean`, `dvi`, `dist`, `test`
- **Google Style**
- Пространство имён: `s21`

## Механика игры "Змейка"

- Игровое поле: **10×20**
- Начальная длина змейки: **4**
- Цель: собрать яблоки, избегая столкновений
- Победа: длина змейки достигает **200**
- Поражение: столкновение со стеной или телом змейки
- Управление: стрелки (только поворот налево/направо)
- Ускорение: через клавишу действия

Дополнительно:

- Подсчёт очков (1 яблоко = 1 очко)
- Хранение и обновление рекорда
- Механика уровней: каждые 5 очков повышается уровень, увеличивается скорость (макс. 10 уровней)

## Интеграция игры "Тетрис"

- Изначально реализован на C как консольная игра
- Перенесён в C++ и адаптирован для Qt
- Поддержка как графического, так и консольного интерфейса
- Применение тех же архитектурных подходов, что и для змейки

## Сборка и запуск

Для сборки проекта используется `Makefile` с поддержкой следующих целей:

### Основные цели

| Цель             | Описание |
|------------------|----------|
| `make all`       | Собрать десктопную и консольную версии игр |
| `make rebuild`   | Очистить и пересобрать проект |
| `make clean`     | Удалить все сборочные артефакты |
| `make install`   | Установить исполняемые файлы в каталог (по умолчанию `src/bins`) |
| `make uninstall` | Удалить установленные исполняемые файлы |

### Работа с тестами

| Цель                | Описание |
|---------------------|----------|
| `make test`         | Запустить unit-тесты (GoogleTest) |
| `make valgrind_test`| Запустить тесты с проверкой утечек памяти через Valgrind |

### Покрытие кода

| Цель                | Описание |
|---------------------|----------|
| `make coverage`     | Сгенерировать HTML-отчёт покрытия кода (LCOV + genhtml) |

### Прочее

| Цель                | Описание |
|---------------------|----------|
| `make dist`         | Создать архив проекта `BrickGame_v2.0.tar.gz` |
| `make dvi`          | Показать справочную информацию о Makefile |
| `make moc`          | Сгенерировать Qt moc-файлы для GUI |
| `make checkformat`  | Проверить стиль кода (clang-format) |
| `make correctformat`| Автоматически привести код к нужному стилю |

> ❗ Для сборки GUI необходим установленный **Qt5** (`Qt5Widgets`, `Qt5Core`), а также **GTest** для тестирования.

После сборки бинарные файлы будут находиться в директории `bin/`:

- `snake_tetris_desktop` — десктопная версия (Qt)
- `snake_tetris_console` — консольная версия (ncurses)
